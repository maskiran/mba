Coursera: [MOOC 1](https://www.coursera.org/learn/marketing-analytics/) [MOOC 2](https://www.coursera.org/learn/digital-analytics/)

## M1 Introduction to Marketing Analytics
* Marketing analytics uses data to measure performance.
* Key metrics include ROI, conversion rates, and customer lifetime value.
* Data sources include web analytics, CRM, and social media.
* Analytics tools help collect and analyze data.
* Data-driven decision making improves marketing effectiveness.

## M2 Web Analytics
* Web analytics tracks website performance.
* Key metrics include traffic, bounce rate, and conversion rate.
* User behavior analysis reveals navigation patterns.
* A/B testing compares different versions.
* Heat maps visualize user interaction.

## M3 Social Media Analytics
* Social media metrics track engagement and reach.
* Sentiment analysis measures brand perception.
* Influencer impact is measured through engagement rates.
* Social listening monitors brand mentions.
* Social ROI measures return on social media investment.

## M4 Email Marketing Analytics
* Email metrics include open rate and click-through rate.
* List segmentation improves targeting.
* A/B testing optimizes subject lines and content.
* Email automation increases efficiency.
* Email ROI measures return on email campaigns.

## M5 Search Engine Analytics
* SEO metrics track organic search performance.
* Keyword performance measures search visibility.
* Backlink analysis evaluates authority.
* PPC metrics include CTR and conversion rate.
* Search ROI measures return on search investment.

## M6 Customer Analytics
* Customer segmentation identifies target groups.
* RFM analysis measures recency, frequency, and monetary value.
* Customer lifetime value predicts long-term value.
* Churn analysis identifies at-risk customers.
* Customer journey mapping tracks touchpoints.

## M7 Attribution Modeling
* Attribution assigns credit to touchpoints.
* Models include last-click, first-click, and multi-touch.
* Data-driven attribution uses machine learning.
* Cross-channel attribution tracks multiple channels.
* Attribution helps optimize marketing spend.

## M8 Predictive Analytics
* Predictive models forecast future behavior.
* Machine learning improves prediction accuracy.
* Customer scoring predicts likelihood to convert.
* Churn prediction identifies at-risk customers.
* Predictive analytics guides marketing strategy.
