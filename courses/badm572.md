## M1 Summarizing Data
* Introduces graphical methods for summarizing data, including frequency tables, histograms, pie charts, and scatter plots.
* Explains basic statistical terms: Data are facts and figures from which conclusions can be drawn; a Variable is any characteristic of an element; a Data set is the data collected for a particular study.
* Shows how to create and interpret bar graphs from frequency tables, including using relative frequency to understand proportions like market share.
* Defines a histogram as a special form of bar graph where numbers are grouped into bins (class intervals) to display frequency.
* Discusses scatter plots for summarizing data with two variables to explore their relationship, such as advertising spend and sales.

## M2 Descriptive Statistics
* Introduces numerical methods for summarizing data, such as calculating the average value.
* Discusses measures of central tendency, specifically the mean and median, and how to calculate them using Excel.
* Explains that the mean is affected by extreme values, while the median is less so, demonstrating this with salary examples.
* Covers the Normal Distribution, describing it as a bell-shaped curve and explaining the empirical rule regarding the percentage of data within 1, 2, and 3 standard deviations of the mean.
* Demonstrates how to use Excel functions like NORM.DIST to calculate probabilities for a given value in a normal distribution and NORM.S.INV to find the Z-score for a given probability.

## M3 Sampling and Central Limit
* Introduces the concept of sampling as a method to produce data and distinguishes between non-probability and probability methods.
* Explains that a larger sample provides a more precise idea about the population.
* Demonstrates using Excel's Data Analysis tool to take random samples from a large dataset.
* Introduces the Central Limit Theorem, stating that the distribution of sample means will be approximately normal for sufficiently large sample sizes, regardless of the original population distribution.
* Explains the payoff of the Central Limit Theorem: enabling the use of the normal curve to understand the distribution of sample means and assess confidence in results using standard error and the empirical rule (e.g., 68%, 95%, 99.7% within 1, 2, 3 standard errors).

## M4 Inference
* Focuses on using sample statistics to make inferences about the population.
* Explains confidence intervals as a range estimated from sample data that is likely to contain the true population parameter.
* Discusses critical values (t-scores and z-scores) used in confidence interval calculations, noting that the z-score of 1.96 is a common value for a 95% confidence interval.
* Demonstrates calculating sample size required to achieve a desired margin of error, particularly for proportions, using a formula involving the proportion, Z-score, and error margin.
* Advises using the proportion closest to 50% from a confidence interval when calculating sample size to ensure the sample is large enough to cover possibilities within that interval.

## M5 Hypothesis
* Introduces the process of hypothesis testing as a key part of statistical inference and the scientific method.
* Explains how to formulate competing hypotheses: the null hypothesis (H0) and the alternative hypothesis (HA).
* Discusses analyzing the results of data collection to test the formulated hypotheses.
* Demonstrates how to perform hypothesis testing for a population mean using sample data and a t-test.
* Shows how to perform hypothesis testing for a population proportion using a z-test and calculate the z-statistic.

## M6 Two Samples
* Focuses on statistical inference when comparing two samples.
* Demonstrates how to formulate hypotheses for comparing two groups, such as testing if the difference between two population means or proportions is zero.
* Covers both one-tail and two-tail tests for comparing two samples.
* Shows how to use Excel's Data Analysis tool to perform two-sample tests.
* Explains how to interpret the results of two-sample tests, including using the p-value to decide whether to reject the null hypothesis.

## M7 Simple Linear Regression
* Introduces simple linear regression as a method to model the relationship between two variables.
* Utilizes scatter plots to visually assess the direction and strength of the relationship between a dependent and independent variable.
* Presents the simple linear regression equation ŷ = b0 + b1x, where b0 is the intercept and b1 is the slope.
* Demonstrates performing simple linear regression analysis using Excel's Data Analysis tool and interpreting the output, including coefficients and p-values.
* Explains R-squared as a measure indicating the proportion of variation in the dependent variable explained by the independent variable.

## M8 Multiple Linear Regression
* Introduces multiple linear regression which extends simple linear regression by allowing more than one independent variable to model a dependent variable.
* Demonstrates how to perform multiple linear regression analysis using Excel's Data Analysis tool by selecting multiple columns for the independent variables.
* Explains the importance of using the Adjusted R-squared in multiple regression as it accounts for the number of independent variables and sample size, providing a better measure of the model's explanatory power than R-squared.
* Discusses how to incorporate categorical data with more than two possibilities into a regression model using dummy variables.
* Mentions that the regression output provides point estimates for predictions but notes that Excel does not automate the calculation of prediction intervals.
